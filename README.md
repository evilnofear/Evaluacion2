# Evaluacion2 - Calculador de Rutas y Narrativa (GraphHopper API)

Script en Python que utiliza las APIs de Geocodificación y Rutas de GraphHopper para calcular distancias, tiempos estimados y obtener una narrativa paso a paso de un viaje entre dos ubicaciones, todo en español.

## Requisitos previos

Asegúrate de tener instalado Python y la librería `requests`. Puedes instalarla ejecutando:
```bash
pip install requests
